**Author:** Rupesh Kumar Sah  

---

## 📌 Executive Overview
This repository contains the end-to-end data science pipeline developed for **PrimeForge Manufacturing Ltd.** to analyze operational bottlenecks, process parameter deviations, and material supplier consistency. The primary objective is to identify root causes of product defects and propose actionable, evidence-based solutions.

---

## 🛠️ Project Structure & Deliverables
* **`DS_SAT_CIA_2.ipynb`**: Python exploratory data analysis (EDA), data cleaning, feature engineering, and model implementation.
* **`DS_SAT_CIA2_Round2.xlsx`**: Excel analysis featuring Pivot Tables (`Pivot_Summary`) and key insights (`Executive_Summary`).
* **`PrimeForge Manufacturing Pitch.pdf`**: 5-slide business pitch presentation detailing strategic quality improvement recommendations.
* **`PrimeForge_Cleaned_Manufacturing_Data.csv`**: Preprocessed dataset used for modeling and analysis.

---

## 📊 Key Findings
1. **Production Line Performance:** Line B exhibited the highest total defect count (**830 defects**), whereas Line D achieved optimal operational efficiency (**630 defects**).
2. **Process Sensor Variations:** Thermal and pressure deviations outside baseline thresholds directly correlate with elevated rework rates.
3. **Supplier Consistency:** Raw material grade variations across suppliers impact final quality pass rates.

---

## 💡 Strategic Recommendations
* **Automated Sensor Controls:** Deploy real-time temperature/pressure threshold safeguards on Line B.
* **Supplier Quality Audits:** Implement strict incoming inspection protocols for underperforming material grades.
* **Predictive Maintenance:** Track equipment operating hours to prevent machine wear and sensor drift.
